# Batalla de Aviones — Mapa de desafíos para MakeCode Arcade

Mapa con 6 desafíos basado en el juego "Avion Multijugador".

| Desafío | Contenidos |
|---|---|
| 1. Despegue | sprites, movimiento, posición |
| 2. ¡Fuego láser! | eventos, proyectiles, tipos |
| 3. Lluvia de caritas | intervalos, aleatoriedad |
| 4. ¡Impacto! | superposiciones, efectos, sonido, puntaje |
| 5. Copiloto | multijugador |
| 6. Contrarreloj | cuenta regresiva, condicionales, fin del juego |
